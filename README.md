# Evolution

Игра про существо из шестиугольных клеток: собираешь его в редакторе, потом
плаваешь в большом мире, таранишь врагов, отбиваешь у них клетки и подбираешь
их, чтобы залечить свои дырки.

Python 3.12 + PyGame (pygame-ce), пакетный менеджер — [uv](https://docs.astral.sh/uv/).

## Запуск

```bash
uv run evolution
# или
uv run python -m evolution
```

## Как играть

**Редактор** (открывается сразу и после каждой гибели):

- **ЛКМ** — поставить клетку (только вплотную к уже стоящим), **ПКМ** — убрать;
- **Tab** — переключиться между кожей и двигателем;
- **Q / E** или **колесо мыши** — куда двигатель толкает;
- **1..9** — какой цифрой он будет включаться (на одну цифру можно повесить
  сколько угодно двигателей);
- бюджет — 20 клеток; **Enter** — в бой.

Жёлтая клетка в центре — сердце: потеряешь его, и существо развалится.

**Бой**:

- цифры **1..9** включают двигатели; толчок сбоку разворачивает существо,
  вода плавно тормозит;
- урон наносит таран: кто разогнался сильнее, тот и выбивает клетку;
- вместе с выбитой клеткой отваливается всё, что держалось через неё, —
  тонкие «шеи» в конструкции опасны;
- голубые клетки в воде подбираются автоматически и лечат по одной утраченной
  клетке; вырасти больше своего чертежа нельзя;
- **Esc** — выход.

Собранное существо сохраняется в `~/.local/share/evolution/creature.json`.

## Структура

- `src/evolution/config.py` — все настройки и числа баланса
- `src/evolution/hexgrid.py` — математика шестиугольной сетки
- `src/evolution/creature.py` — чертёж, клетки, существо и его физика
- `src/evolution/physics.py` — столкновения и отрыв клеток
- `src/evolution/world.py` — мир, еда, спавн врагов
- `src/evolution/ai.py` — облик и поведение врагов
- `src/evolution/render.py` — отрисовка
- `src/evolution/editor.py` — экран сборки существа
- `src/evolution/scenes.py` — экраны боя и гибели
- `src/evolution/game.py` — игровой цикл
